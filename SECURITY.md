# Security Policy

## Meldeweg

Bitte **kein** oeffentliches Issue fuer Sicherheitsprobleme. Nutze
GitHub Security Advisories ("Report a vulnerability") in diesem Repository.

## Umfang

- **Im Umfang:** dieses Repository - Konfiguration, Templates, Skripte.
- **Nicht im Umfang:** der produktive Host. Es gibt keinen Testzugang, und
  ohne schriftliche Freigabe wird nicht gegen ihn getestet.

## Was eine Meldung braucht

Betroffene Datei und Commit, Auswirkung, reproduzierbare Schritte.
