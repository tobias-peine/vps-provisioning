# Backlink-Plan kisium.de

Stand 17.11.2026. Search-Console-Links-Export: **0 Datenzeilen**. Das ist die
Ausgangslage — nicht „keine Links möglich“, sondern „noch keine redaktionellen Links“.

Konkrete, geprüfte Ziele: `docs/seo/outreach-targets-20261117.md`.

## Prinzipien

- Keine gekauften Links, keine Link-Tausch-Netzwerke, keine Massenmails.
- Nur verlinken, wo der Artikel eine echte Frage beantwortet.
- GitHub/LinkedIn/Mastodon sind Distribution, keine SEO-Backlinks (`nofollow`).
- Jede Anfrage personalisiert; ein konkreter Bezug zum Zielmedium.

## Linkable Assets

1. **VPS absichern: Debian-Checkliste** — praktisch, mit Befehlen, Docker-Falle.
2. **Backup-Ziel mit Hetzner Storage Box** — konkrete Fehler, Restore, Kosten.
3. **Patchday: 17 Pakete, vier Fehler** — messbar, ehrlich, mit Logs.
4. **Ansible: 356 Sekunden** — Zahl, Kaltstart, drei Fehler.
5. **Homelab: ein VPS, Docker und drei Fehler** — Architektur + Learnings.
6. **Bewerbung als Quereinsteiger** — Vorlage, Checkliste, drei Fehler.

```text
[URL]. Darin geht es um [konkretes Problem/Ergebnis], inklusive [Zahl/Fehler/Code].

Falls das thematisch passt: Ich würde mich über eine Verlinkung oder einen
Gastbeitrag freuen. Wenn nicht, auch kein Problem — dann freue ich mich über
eine kurze Rückmeldung, was dir fehlt.

Viele Grüße
Tobias
```

## Nächste konkrete Schritte

1. 10 Ziele auswählen, die wirklich zu Linux/Docker/Homelab/Quereinstieg passen.
2. Je Ziel einen konkreten Artikelbezug heraussuchen.
3. Fünf personalisierte Anfragen pro Woche, nicht mehr.
4. Nach 14 Tagen nachfassen — einmal.
5. Verlinkte URLs in die Tabelle eintragen; Search-Console-Links-Report beobachten.

## Was nicht hilft

- 100 generische „Bitte verlinken“-Mails.
- Kommentarspam oder Forum-Links ohne Antwort auf die Frage.
- Linktausch mit irrelevanten Seiten.
- Bezahlte Linkpakete.
