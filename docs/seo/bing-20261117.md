# Bing-Indexierung für kisium.de

Stand 17.11.2026. Ziel: Bing soll die Seite unabhängig von Google crawlen und
indexieren. Keine Garantie — Sitemap und URL-Meldung beschleunigen nur.

## Status

- **17.11.2026:** Import aus der Google Search Console automatisch erfolgt
  (Nutzerangabe). Die Property ist damit in Bing Webmaster Tools vorhanden.
- **Nicht verifiziert:** Sitemap-Status, Indexierung, URL Inspection.
- Import ≠ Indexierung. Bing crawlt und indexiert unabhängig; das kann Tage
  bis Wochen dauern.

## Nächste Prüfung

1. **Sitemaps:** Ist `https://kisium.de/sitemap.xml` automatisch übernommen?
   Wenn nicht, manuell hinzufügen.
2. **URL Inspection:** VPS-Pillar und Backup-Post prüfen: „Indexed“ oder
   „Discovered“.
3. **URL Submission:** Falls die Seiten nicht gefunden wurden, die fünf
   wichtigen URLs manuell melden.
4. **robots.txt:** Bingbot darf nicht blockiert sein.
5. **24.11.2026:** erneut prüfen; vorher keine weiteren Änderungen.

## 1. Konto und Import

1. https://www.bing.com/webmasters öffnen, mit Microsoft-Konto anmelden.
2. **Import from Google Search Console** wählen.
3. `https://kisium.de/` auswählen und importieren.
4. Prüfen, ob die Property als **verifiziert** erscheint. Wenn nicht: manuell
   verifizieren (DNS-TXT, XML-Datei oder Meta-Tag).

Der Import übernimmt in der Regel die Property; die Sitemap kann trotzdem neu
eingereicht werden.

## 2. Sitemap einreichen

- Bing Webmaster Tools → **Sitemaps** → Sitemap hinzufügen:
  `https://kisium.de/sitemap.xml`
- Status prüfen: „Success“ / „Erfolgreich“.
- Die Sitemap ist ein **Index**; Bing liest die enthaltenen Unterseiten selbst.
- Nicht täglich neu einreichen. Änderungen werden über den Lastmod erkannt.

## 3. Wichtige URLs melden

Bing Webmaster Tools → **URL Submission** (URLs übermitteln):

- `https://kisium.de/`
- `https://kisium.de/vps-absichern-debian-checkliste/`
- `https://kisium.de/ein-backup-ziel-das-einen-nachmittag-gebraucht-hat/`
- `https://kisium.de/zertifikate/`
- `https://kisium.de/bewerbung-quereinsteiger/`

Das Tageskontingent ist begrenzt; die Sitemap deckt den Rest ab. Nicht mehrfach
am selben Tag einreichen.

## 4. Prüfen

- **URL Inspection** in den Webmaster-Tools: „Indexed“ oder „Discovered“.
- **Site Explorer**: welche Seiten gefunden wurden.
- Bing-Suche: `site:kisium.de` — nur eine schnelle, keine belastbare Kontrolle.
- Indexierung dauert Tage bis Wochen; Backlinks und interne Links beschleunigen.

## 5. robots.txt

Sicherstellen, dass Bingbot nicht blockiert ist:

```text
User-agent: *
Allow: /

Sitemap: https://kisium.de/sitemap.xml
```

## 6. IndexNow (optional, später)

IndexNow meldet geänderte URLs sofort an Bing, Yandex, Seznam und Naver — **nicht**
an Google. Dafür braucht es:

1. Key-Datei unter `https://kisium.de/<key>.txt` mit dem Key als Inhalt.
2. Einen Ping an `https://api.indexnow.org/indexnow` mit Host, Key und URL-Liste.
3. Automatisierung beim Ghost-Publish (Webhook/Skript).

Das lohnt erst, wenn regelmäßig neue Artikel erscheinen. Für die ersten Wochen
reichen Sitemap und manuelle URL-Meldung.

## Was noch offen ist

- Bing-Import und Sitemap-Status sind nur im eingeloggten Konto sichtbar.
- Nach dem Import 3–7 Tage warten, dann URL Inspection prüfen.
- Keine weiteren Title-/Content-Änderungen nur für Bing.
